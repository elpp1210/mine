# byunjiwon.com

변지원 작가 포트폴리오. 바탕화면에 누끼 작업들이 아이콘처럼 떠 있는 사이트입니다.

## 내용 고치기

1. https://app.pagescms.org 에서 깃허브 계정으로 로그인합니다.
2. `elpp1210/mine` 저장소를 고르고 **포트폴리오** 메뉴로 들어갑니다.
3. 작업, 작가 이력, 스테이트먼트, 사이트 설정을 고치고 **Save**를 누릅니다.
4. 1~2분 뒤 byunjiwon.com에 반영됩니다.

누끼 아이콘은 배경을 지운 투명 PNG로 올려 주세요.

## 파일 구성

- `index.html`: 사이트 화면 (바탕화면, 창, 드래그)
- `content/site.json`: 작업, 이력, 스테이트먼트, 배경색 등 모든 내용
- `images/`: 이미지 파일
- `.pages.yml`: Pages CMS 관리 화면 설정
- `CNAME`: 연결할 도메인 (byunjiwon.com)
