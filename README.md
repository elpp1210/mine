# byunjiwon.com

변지원 작가 포트폴리오. 바탕화면에 누끼 작업들이 아이콘처럼 떠 있는 사이트입니다.

## 내용 고치기

1. byunjiwon.com/#admin 으로 들어갑니다.
2. 처음 한 번은 안내에 따라 깃허브 관리 열쇠(토큰)를 만들어 붙여 넣습니다. 그 브라우저에서는 다음부터 오른쪽 아래 톱니바퀴로 바로 열립니다.
3. 작업, 이력, 스테이트먼트, 사이트 설정을 고치고 **저장하고 게시**를 누르면 1~2분 뒤 사이트에 반영됩니다.

바탕화면 아이콘을 끌어 놓은 위치도 함께 저장됩니다. 누끼 아이콘은 배경을 지운 투명 PNG로 올려 주세요.

## 파일 구성

- `index.html`: 사이트 화면 (바탕화면, 창, 드래그)
- `content/site.json`: 작업, 이력, 스테이트먼트, 배경색 등 모든 내용
- `images/`: 이미지 파일
- `CNAME`: 연결할 도메인 (byunjiwon.com)
